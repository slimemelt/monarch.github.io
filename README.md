# Monarch

Landing page for monarch.bloomnetworks.net.

Hosted on GitHub Pages from `main`. `CNAME` is `monarch.bloomnetworks.net`; in Cloudflare DNS add `CNAME monarch -> slimemelt.github.io` with the proxy off.

`404.html` forwards short links (for example `/discord`) managed in the Yeeps admin. Anything unknown goes to the homepage.
